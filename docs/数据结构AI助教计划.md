根据仓库现有素材，选定课程为 **《数据结构》（王道考研数据结构 8 章体系）**。

## 7. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 原始 PDF 过大（约 1.1 GB） | 上传慢、检索效果差、仓库膨胀 | 筛选语料转文本入库，原始文件不入库或 Git LFS |
| 中文 embedding 效果弱 | 召回不准 | 改用中文/多语 embedding（如 `bge-small-zh-v1.5`），并开启混合检索 |
| PDF 公式/图片转文本丢失 | 习题与公式类回答不准 | 教材/讲义题目保留图片引用；公式改为文字描述或 LaTeX |
| DeepSeek 无内置 embedding | 不能直接用模型供应商做 embedding | 使用本地 sentence-transformers 中文模型或外部 embedding API |
| 工具只在提示词层面实现 | 不满足 item.docx“真实扩展”要求 | 以 Python + JSON/SQLite + pytest 先行实现，再接入 Workspace Tool/MCP |
| 题目/作业版权与学术诚信 | 不合规风险 | 题库来源于课程资料与小组整理；助教拒绝代写整份作业 |
| 时间被压缩 | 无法完成全部优化 | 先保证 15 问、2 个真实工具、1 次对比，再扩展 |
