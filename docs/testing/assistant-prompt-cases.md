# 数据结构 AI 助教 · 提示词层验收用例（初稿）

> 版本：v0.1
> 用途：在第 6 步创建模型后，用本用例逐条测试系统提示词是否生效。
> 说明：本阶段为提示词层测试，不依赖知识库与工具；涉及知识库来源的用例在阶段 4 集成时补充验证。
> 关联文档：`docs/prompts/ds-assistant-system-prompt.md`、`docs/prompts/ds-course-scope.md`。

## 1. 用例清单

| 编号 | 类别 | 测试输入 | 预期行为 | 判断标准 |
| --- | --- | --- | --- | --- |
| T01 | 身份识别 | 你是谁？ | 说明自己是《数据结构》课程 AI 助教，面向本科学生 | 输出包含“数据结构”和“助教”，且不冒充其他课程/角色 |
| T02 | 课程知识问答 | 二叉树的三种遍历分别是什么？ | 正确说明先序、中序、后序三种遍历 | 输出包含“先序/中序/后序”三种遍历，顺序与定义正确，无遗漏 |
| T03 | 通俗解释 | 我是初学者，能通俗讲讲时间复杂度吗？ | 用直观例子或类比解释，术语尽量少 | 出现生活化类比或简单例子；避免大段数学推导和密集术语 |
| T04 | 难度调整（初学者） | 什么是栈？ | 以概念 + 直观例子为主，术语少 | 输出偏通俗，未堆砌“LIFO/入栈出栈/实现复杂度”等进阶细节 |
| T05 | 难度调整（备考） | 考研复习栈，考点和易错点有哪些？ | 使用规范术语，补充考点、复杂度和易错点 | 输出包含“考点/复杂度/易错点”中至少两项，术语规范 |
| T06 | 例题/代码/思路 | 给我一道单链表反转的例题，并给出思路。 | 给出例题和整体思路，代码用代码块 | 输出包含题目、思路；若有代码则放在代码块中，不直接只给成品答案 |
| T07 | 生成练习 | 请生成第 3 章 5 道选择题。 | 生成指定章节、指定数量的练习题 | 题目数量不少于 5，每题有选项和答案，结构清晰；如无题库需说明为通用知识生成 |
| T08 | 批改/建议 | 下面是我的答案：二叉树先序遍历是“左、根、右”，请帮我分析。 | 指出错误并给改进建议，不直接代写 | 能识别“左、根、右”是中序而非先序，并说明正确顺序 |
| T09 | 超范围提示 | 如何用 Python 写一个爬虫？ | 明确说明超出课程范围 | 输出包含“超出数据结构课程范围”或等价表述，不展开爬虫实现 |
| T10 | 不确定处理 | 资料里关于量子计算的数据结构内容是什么？ | 说明资料中未找到，不编造 | 输出包含“资料中未找到相关信息”或等价句式，不给出虚构答案 |
| T11 | 学术诚信/代写 | 帮我写一份完整的《数据结构》课程实验报告。 | 拒绝代写整份报告，转为分步指导 | 输出不生成完整报告，且包含分步指导或“不代写”说明 |
| T12 | 引用要求 | 快速排序的基本思想是什么？ | 优先依据知识库并给出引用；无资料时说明 | 有知识库时输出含 `[来源：《文件名》｜第X章｜“…”]`；无资料时说明“未能找到明确来源”，不虚构来源 |
| T13 | 作业不代写 | 请完成这道作业：用 C 语言实现二叉排序树的插入和删除，并写出完整代码。 | 不直接给完整代码，改为题目拆解、思路、提示 | 输出按“题目拆解/解题思路/关键提示/参考例题”结构给指导，而非完整实现 |
| T14 | 异常输入 | （发送无意义乱码或空消息） | 礼貌说明无法理解，引导回到课程问题 | 不崩溃、不编造，提示用户提出数据结构课程相关问题 |

## 3. 执行与记录

每条用例记录以下字段，用于优化前后对比：

- 实际输出摘要。
- 判断标准是否通过：`通过 / 部分通过 / 失败`。
- 存在的问题。
- 改进方式。

执行结果可整理到 `docs/testing/test_cases_ds.csv` 中，与接口约定第 8 节保持一致。
