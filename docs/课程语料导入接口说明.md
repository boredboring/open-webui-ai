# 课程语料前端导入功能说明

## 目的

解决“语料在服务器 `data/corpus` 目录、但前端无法直接访问本地磁盘”的问题：知识库页面可查看服务器语料，勾选后直接导入 Open WebUI 并完成知识向量化。

## 使用入口

1. 启动系统后进入 Workspace → Knowledge → “数据结构课程知识库”。
2. 点击右上角“添加内容（+）”下拉。
3. 选择“从课程语料导入”。
4. 弹窗会列出服务器 `data/corpus` 下的 Markdown：
   - 按 `01_绪论 ~ 08_排序 / 90_习题代码 / 91_试卷` 分组；
   - 已导入当前知识库的文件标记“已导入”且不可重复勾选；
   - 可勾选单个文件、整章或“全选”。
5. 点击“导入到知识库”，后端逐个读取文件、写入平台文件库并向量化到当前知识库。

导入完成后，知识库文件列表会自动刷新。

## 后端接口

### 1. 获取语料清单

```http
GET /api/v1/course/corpus/files
Authorization: Bearer <token>
```

任意已登录用户可调用（导入仍要求管理员或知识库创建者）。

响应示例：

```json
{
  "root": "D:/Open-webui/open-webui-ai/data/corpus",
  "exists": true,
  "total": 105,
  "items": [
    {
      "path": "01_绪论/1.1_数据结构的基本概念.md",
      "filename": "1.1_数据结构的基本概念.md",
      "directory": "01_绪论",
      "source_type": "课件",
      "chapter": "第一章 绪论",
      "module": "1.1_数据结构的基本概念",
      "size_bytes": 145000,
      "modified_at": 1756814000000
    }
  ],
  "generated_at": "2026-09-03T12:00:00+00:00"
}
```

### 2. 导入语料到知识库

```http
POST /api/v1/course/corpus/import
Authorization: Bearer <token>
Content-Type: application/json
```

请求体：

```json
{
  "knowledge_id": "1dfc8828-d243-41c7-97e0-0f46453065d9",
  "files": [
    "01_绪论/1.1_数据结构的基本概念.md",
    "08_排序/8.5.2 基数排序.md"
  ]
}
```

响应示例：

```json
{
  "knowledge_id": "1dfc8828-d243-41c7-97e0-0f46453065d9",
  "total": 2,
  "imported": [
    { "path": "01_绪论/1.1_数据结构的基本概念.md" }
  ],
  "skipped": [
    { "path": "08_排序/8.5.2 基数排序.md", "reason": "已在知识库中" }
  ],
  "failed": []
}
```

约束：

- `files` 中路径必须位于 `data/corpus` 内，禁止 `..`/绝对路径穿越。
- 调用者必须是管理员或该知识库创建者。
- 已存在同名文件会跳过；已导入文件再次导入不会重复向量化。

## 配置说明

语料根目录默认为仓库下 `data/corpus`（按 `course.py` 所在位置自动推导）。若后端与语料不在同一目录，可设置环境变量：

```powershell
$env:COURSE_CORPUS_DIR = "D:\Open-webui\open-webui-ai\data\corpus"
```

## 涉及改动

| 文件 | 改动 |
| --- | --- |
| `backend/open_webui/routers/course.py` | 新增语料清单与导入接口 |
| `backend/open_webui/main.py` | 注册 `/api/v1/course` 路由 |
| `backend/tests/test_course.py` | 路径安全、权限、清单格式测试 |
| `src/lib/apis/course/index.ts` | 前端 API 封装 |
| `src/lib/components/workspace/Knowledge/KnowledgeBase/CorpusImportModal.svelte` | 语料浏览/勾选/导入弹窗 |
| `.../KnowledgeBase.svelte`、`AddContentMenu.svelte` | “从课程语料导入”入口 |
