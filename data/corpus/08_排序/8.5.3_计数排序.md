空间复杂度 = O(n + k)
时间复杂度 = O(n + k)
若 k = O n ,计数排序的时间复杂度
= O n ,此时计数排序的时间效率优
于快速排序、堆排序等排序算法的
O n log! n
若 k > O n log! n ,计数排序的时间
复杂度 > O n log! n ,此时计数排序
的时间效率不如快速排序、堆排序等
排序算法的O n log! n
• 计数排序是典型的“空间”换“时间”思想
• 适用场景:当待排序数组的取指范围 k 较小
时,可以考虑使用计数排序的思想
