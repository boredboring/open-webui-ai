回顾开放定址法的几种常用“探测序列”
di = 0, 1, 2, 3, ..., m-1
di = 02, 12, -12, 22, -22, ..., k2, -k2。其中k≤m/2
di 是一个伪随机序列,如 di= 0, 5, 3, 11, ...
di = i×hash2(key)。其中 hash2(key) 是另一散列函数
开放定址法:Hi = (H(key) + di) % m ,其中,Hi 表示第 i 次发生冲突时的散列地址;i = 0,
