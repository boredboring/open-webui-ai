## 文件格式约定

每个 PDF 对应一个 Markdown 文件，统一格式为：

```markdown
---
source_type: 课件        # 课件 / 习题代码 / 试卷
course: 数据结构
chapter: 第一章 绪论     # 非章节资料为 -
module: 1.1_数据结构的基本概念
source: data/PPT/.../1.1_数据结构的基本概念【公众号：研料库，料最全】.pdf
pages: 29
generated: 2026-09-03
---

# 第一章 绪论 · 1.1_数据结构的基本概念

> 类型：课件｜课程：数据结构｜共 29 页

## 第 4 页

正文……
```

约定要点：

1. 按章节建目录、按原始视频/课件模块建文件，方便回答时引用“第 X 章 + 模块名”。
2. 每页使用 `## 第 N 页` 二级标题，便于 Markdown 标题切分和定位来源。
3. 文件头保留原始 PDF 路径，便于回溯原文。
4. 文件名中的 `【公众号：研料库，料最全】` 等营销水印已清理。

## 入库建议

1. 在 Open WebUI 的 Workspace → Knowledge 中新建“数据结构课程知识库”，按目录上传这些 `.md` 文件。
2. 建议开启 RAG 的“Markdown 标题切分”（`ENABLE_RAG_HEADER_SPLIT` / 后台 Markdown Header Text Splitter），本语料按页/模块组织，切分结果可预期。
3. 若检索时公式或代码类问题召回不足，可将对应原始 PDF 单独上传补充，并考虑中文 embedding 与混合检索。

## 已知限制

- PDF 文字层提取：图片型公式、树/图示意不会转成文字；若某模块 Markdown 很短，说明该 PPT 以图示为主。
- 代码题 PDF 中代码的空格/缩进在提取时可能丢失，例如 `#definemaxsize50`，需与原始 PDF 对照。
- 扫描版《王道数据结构》教材（420 页）无文字层，未纳入本语料；如需要，可后续用 OCR 转换。
- 试卷 PDF 存在防复制水印造成的乱序/重复字符，正文可检索，但排版不以原文为准。

## 上传到 Open WebUI 知识库

### 平台内置“从课程语料导入”

1. 打开 Open WebUI → Workspace → Knowledge，进入已创建的“数据结构课程知识库”。
2. 点击“添加内容（+）”下拉中的“从课程语料导入”。
3. 系统会读取服务器 `data/corpus` 下的 Markdown 并按章节展示，勾选后点击“导入到知识库”。

该功能会复用 Open WebUI 的文件处理与向量化链路，已在知识库中的同名文件会自动跳过。
